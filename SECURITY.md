# Security policy

## Scope

This repository is a **synthetic educational exercise**, not a production logistics system. Do not add customer, shipment, location, pricing, account, or other operational data. Do not commit credentials, tokens, `.env` files, private keys, or solver licences.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to the repository owner through GitHub. Do not include secrets or sensitive operational data in public issues.

## Safe use

Review any data before use. The bundled instance is deliberately fictional and small. This project has no network calls, no data upload feature, and no production-service integration.
